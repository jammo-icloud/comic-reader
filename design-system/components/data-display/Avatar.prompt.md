The user identity glyph — an accent-tinted circle with the username's first letter. The trigger for the profile menu.

```jsx
<Avatar username="Jammo" size="md" />
<Avatar username="Jammo" size="lg" />
<Avatar username="Jammo" variant="onDark" />   {/* over a dark cover hero */}
```

Sizes: `sm` (24), `md` (32, default), `lg` (44). The `onDark` variant swaps to dim white-on-translucent for floating use over cover art.
